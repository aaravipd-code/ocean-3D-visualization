Why AquaCore

Ocean data is scattered. We put it in one place.

The Problem

Model output and real measurements live apart

Numerical ocean model output sits in NetCDF files viewed with specialist tools, while in-situ observations from ARGO floats and stations sit in separate logs and spreadsheets. Comparing the two — the basic task of checking whether a model is accurate — is slow and manual.

Our Solution

One interactive 3D platform for both

AquaCore renders model fields as an explorable 3D ocean, overlays real observation stations on the same view, and computes the model-vs-observation difference automatically — so researchers spend time on analysis, not data wrangling.
